1. Resumo Executivo

Este relatório apresenta uma visão executiva consistente do ecossistema Hermes no mês de junho de 2026, refinando a identificação de faturamentos para dar maior segurança à tomada de decisão.

O principal componente financeiro diretamente atribuível ao Hermes é o Vertex AI. O custo operacional computacional observado para o endpoint /webhook em Cloud Run foi extremamente baixo e residual.

Existem custos compartilhados ou não atribuídos na billing account geral, como Cloud Run, Cloud Build e Cloud Run Functions, que contêm recursos de outros workloads e não podem ser automaticamente tratados como custo exclusivo do Hermes.

Natureza Gerencial: Este documento fornece uma visão gerencial e executiva com máxima transparência metodológica. Ele não representa e não deve ser confundido com um rateio contábil exato ou balanço financeiro fechado do Hermes.

7. Premissas e Limitações

  • • Vertex AI foi tratado como o único faturamento diretamente atribuível ao Hermes.
  • • Cloud Run, Cloud Build e Cloud Run Functions foram tratados como custos agregados compartilhados ou não atribuídos na conta GCP.
  • • A base de faturamento brutas do export disponível é consolidada por tipo de recurso provisionado ao nível do provedor GCP, e não por workload individual.
  • • A estimativa de consumo do Cloud Run foi baseada em logs de telemetria física obtidos no Cloud Logging.
  • • O relatório não representa um custo total contábil fechado, mas sim uma modelagem racional gerencial executiva para tomada de decisão.
