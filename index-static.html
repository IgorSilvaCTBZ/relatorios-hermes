1. Resumo Executivo

Este relatório apresenta uma visão macro do custo estimado do ecossistema Hermes no mês de junho de 2026.

O custo de Vertex AI é tratado como diretamente atribuível ao Hermes, pois apenas o Hermes utiliza esse serviço.

Os custos de Cloud Run e Cloud Build foram tratados como estimativas parciais para o Hermes, pois existem outros workloads compartilhando esses serviços.

O objetivo é oferecer uma leitura executiva, com transparência sobre o que é custo observado e o que é custo estimado.
